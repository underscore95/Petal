# Petal

Petal is a hobbyist 3D Vulkan game engine that is currently not accepting contributors.

See [Documentation](https://github.com/underscore95/Petal/tree/main/Documentation) for more information.

## Current State
### Rendering

A low level abstraction over Vulkan exists, with Slang shaders and automatic descriptor creation via shader source reflection.

A higher level rendering API will be created in the future.
